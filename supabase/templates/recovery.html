Tilbakestill passord

Vi mottok en forespørsel om å tilbakestille passordet for kontoen din. Klikk på knappen under for å velge et nytt passord.

{{ if eq .RedirectTo "https://admin.astudent.no/auth/update-password" }} Tilbakestill passord {{ else }} Tilbakestill passord {{ end }}

Hvis knappen ikke fungerer, kan du kopiere og lime inn denne lenken i nettleseren:
{{ if eq .RedirectTo "https://admin.astudent.no/auth/update-password" }} {{ .RedirectTo }}?token_hash={{ .TokenHash }}&type=recovery {{ else }} {{ .ConfirmationURL }} {{ end }}

Sikkerhet: Hvis du ikke ba om å tilbakestille passordet, bør du kontakte oss umiddelbart.

Trenger du hjelp? Kontakt oss på it@astudent.no.
